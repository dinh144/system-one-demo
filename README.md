# System-One memory-control demo

Local, non-commercial research demo for comparing memory decisions.

## Quick start
1. `python -m demo setup`
2. `python -m demo doctor`
3. `python -m demo run`
See [HANDOFF.md](HANDOFF.md) for Windows setup and troubleshooting.

The demo UI is prebuilt in `web/out/`; Node.js is not needed to run it. A recorded backup run (replay data and a video, both labelled with the machine they were recorded on) is in `data/`.
